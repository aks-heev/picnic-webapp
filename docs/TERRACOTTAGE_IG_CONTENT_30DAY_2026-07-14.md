## A. 8 Reel Concepts

### R1 · Transformation — Umber birthday (HERO, shoot first)
- **Hook (0–1.5s):** locked-off wide of the bare room, lights half-off. Top-caption: **"this room has 3 hours to become a birthday"**
- **Shots:** bare room (1s) → 6–8 hard cuts @ ~0.7s: drapes going up, balloons, fairy lights coiled then lit, cake placed, letters spelled out → cut to black (0.3s) → lights-on full reveal, slow push-in (3s)
- **Arc:** dark→bright lands on the reveal. End-card: logo watermark + "DM 'BIRTHDAY'"
- **Caption:** "Every setup is built same-day, in-room, before check-in. Umber fits 2 [+kids?]. DM 'BIRTHDAY' for dates + the setup menu."
- **Why first:** it IS the product demo, and it doubles as the warm ad creative.

### R2 · Bridge — the proven formula, remade for stays
- **Hook:** best existing picnic clip (recognizable to the warm audience). Top-caption: **"you loved our picnics"**
- **Shots:** 2–3 picnic hits (2s total) → whip-pan / door-open transition → cottage interior → setup reveal → couple/guests settling in (use real guest footage only with permission; else staged)
- **Top-caption line 2 on the turn:** **"now stay the night"**
- **Caption:** "Same team, same care — but you don't go home at 9pm. Stays + celebration setups at TerraCottage, Gurugram. Link in bio."
- **Note:** this is the collab anchor — pin it on both profiles.

### R3 · Occasion POV — birthday
- **Hook:** POV hand pushing the door open. Top-caption: **"POV: he booked the whole cottage for your birthday"**
- **Shots:** continuous-feel POV: door → hallway/arch → room reveal → close-ups (cake, candles, name letters) → pan to [balcony/bathtub/projector — whatever is real]
- **Audio:** trending soft-emotional audio (swap per week; the POV format survives audio changes)
- **Caption:** "Tag the one who should see this. DM 'BIRTHDAY' for dates."

### R4 · Price transparency — "what ₹10,000 gets you"
- **Hook:** top-caption: **"what ₹10,000 actually gets you here"** over the finished Ochre setup
- **Shots:** receipt-style text lines appearing one by one over matching shots: "the room, all night — ₹X" → "full decor setup — ₹X" → "[cake / add-ons] — ₹X" → total card: "₹10,000. no surprises at checkout."
- **Caption:** "We'd rather you know the price before you DM. Ochre setups start lower; Umber premium runs ₹16–18k. Menu in highlights."
- **Why:** transparency is rare in this niche and pre-qualifies WA leads — fewer "price?" dead-ends.

### R5 · Transformation — Ochre (accessible tier)
- **Hook:** top-caption: **"a birthday that doesn't need a ₹50k budget"**
- **Shots:** same structure as R1, faster (Ochre is the smaller room): bare → 5 cuts → reveal
- **Caption:** "Ochre: our cozier room, setups from ₹[X]. Same care, smaller bill. DM 'OCHRE'."
- **Note:** this is the downsell creative — runs organic only; ads stay on Umber (highest AOV).

### R6 · Proposal — hidden setup
- **Hook:** normal-looking check-in footage. Top-caption: **"she thinks it's just a staycation"**
- **Shots:** casual arrival, bags down → second door opens → proposal setup reveal (candles path, flowers, ring box on table) → cut before any "answer" (leave it open)
- **Caption:** "We've done this quietly more than once. If you're planning one, DM 'PROPOSAL' — we keep secrets professionally."
- **Guard:** only claim "more than once" if true; otherwise cut that line.

### R7 · BTS / trust — the 3 hours before check-in
- **Hook:** timer graphic + top-caption: **"what happens 3 hours before you arrive"**
- **Shots:** checklist on clipboard → linen steaming → flower trimming → light-string test → final walkthrough → door closes behind the team as guests' car arrives
- **Caption:** "The setup isn't a prop drop — it's built fresh for every booking. By the team behind The Picnic Stories."
- **Why:** justifies the price without arguing about it.

### R8 · Whole home — Sienna group play
- **Hook:** top-caption: **"book both rooms and the cottage is yours"**
- **Shots:** exterior → both rooms quick-cut → shared spaces → long table / group setup dressed for a party
- **Caption:** "Group birthdays, small family dos, joint anniversaries — the whole place, no strangers on the other side of the wall. DM 'COTTAGE'."
- **Note:** monsoon-safe framing — all interior shots.

**Production reality check:** 8 concepts ≈ 5 weeks at the committed 1–2/wk. Schedule 6 in the first 30 days (below); R5 + R8 are the bank. Batch-shoot R1/R3/R7 on one real setup day — one booking's prep yields three reels.

## B. Seed Grid — 12 posts, live before any ad runs
Order matters: the grid is what ad-clickers judge. Post 3–4/day across days 1–4.

1. Brand intro card — logo, one line: "Private cottage stays + celebration setups · Gurugram · by The Picnic Stories"
2. Umber room tour — 5–7 photo carousel, honest angles
3. Ochre room tour — same treatment
4. Setup menu card — 3 tiers per room, occasion-mapped (mirror of the WA catalog)
5. Transparent pricing card — static version of R4's receipt
6. Birthday setup photoset (real setup, best 6 frames)
7. Anniversary / date-night setup photoset
8. "How booking works" carousel — DM → pick date → ₹3,000 advance → check-in (4 slides)
9. Guest words — 1–3 review screenshots/quotes [with permission]
10. Proposal setup photoset (no faces needed)
11. The cottage itself — exterior, arches, textures; location context [true one-liner, e.g. "in Gurugram, X min from Y" — verify before writing]
12. Team/founder note — who we are, why we started doing setups ("same hands behind The Picnic Stories picnics")

Highlights to create from these: **Rooms · Setups · Pricing · Reviews · How to book**

## D. WhatsApp Qualification Script

**Auto-greeting (set in WA Business):**
"Hi! You've reached TerraCottage 🧡 — stays + celebration setups in Gurugram, by The Picnic Stories. Tell us: **what's the occasion, and what date?**"

**Flow (quick replies in brackets):**
1. Occasion + date → check calendar. If free: "Lovely — [date] is open."
2. Guests? → room reco: 2 guests → Umber (default pitch) or Ochre (budget signal); groups → Sienna whole-home.
3. **Pitch high first:** send Umber premium tier card + 2 best photos. "Most-booked for [occasion]: ₹16–18k, includes stay + [tier inclusions]."
4. Price hesitation → downsell, don't discount: "If that's above budget, Ochre with the [tier] setup lands around ₹[X] — same setup care, cozier room." Then, only if still stuck: offer the founding-offer upgrade (per plan §7) — never a price cut.
5. Close: "₹3,000 advance locks the date (adjusted in the total). UPI or payment link?"  → send Razorpay link.
6. Confirm: "You're locked for [date] 🎉 — we'll message [2 days] before check-in with timings. Anything you want us to sneak into the setup?"
7. **Log it immediately:** admin → + Add Booking → `external_booking_ref = IG-ad / IG-organic / IG-story` → send_guest_email ON if email captured. No log, no attribution, no CAC.

**Not-ready leads:** "No rush — want me to send the full setup menu PDF so you have it? And roughly when's the occasion?" → note month, follow up once ~2 weeks prior. One follow-up, not a drip.

**SLA:** first reply <15 min, 10:00–22:00. Assign the phone owner by name before ads start.
